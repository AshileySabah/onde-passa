## Como executar

### Backend

1. Na pasta `backend`, rode `npm install`

2. Crie o arquivo `.env` a partir do `.env.example` e preencha `TMDB_TOKEN` com o seu token do TMDB. Para obter o token:
   - logue ou crie uma conta em https://www.themoviedb.org
   - em https://www.themoviedb.org/settings/api crie uma chave para uso pessoal ou utilize uma já existente se tiver
   - use o valor de "Token de Leitura da API"

3. Rode `npm run dev`

### Aplicativo

1. Na pasta `mobile`, rode `npm install`

2. Rode `npx expo start`

3. Escaneie o QR Code no app do Expo Go no celular
